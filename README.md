# 通用语音插件

AstrBot 语音插件 —— 在群聊中发送角色名或台词关键词，自动回复对应语音片段。支持**多语音库**（默认内置三国杀语音库，可自由添加其它语音库）、**mp3/wav/m4a** 三种格式、关键词精确匹配与模糊匹配，并能智能判断是否需要调用 LLM 回复。

## 功能一览

| 功能 | 触发方式 | 示例 |
|------|----------|------|
| 点播指定语音 | `角色名+序号` | `SP关羽3` → 发送 SP关羽 第 3 条语音 |
| 发送全部语音 | `角色名+0` | `曹操0` → 依次发送曹操所有语音（超出 5 条自动合并） |
| 随机播放 | `角色名`（不带序号） | `周瑜` → 随机发送一条周瑜语音（不重复） |
| 精确点播（多库重名） | `语音库名+角色名+序号` | `三国杀曹操3` → 指定语音库内的曹操 |
| 随机台词 | `随机台词+数字` | `随机台词3` → 从全部角色中随机 3 条语音（上限 5 条） |
| 角色列表 | `角色列表` / `角色列表 <库名>` | 返回全部或指定语音库的角色图片（按拼音排序；兼容旧触发词「英雄列表」） |
| 关键词匹配 | 消息中包含台词关键词 | `不可能` → 发送 "不可能，绝对不可能" 语音 |
| 模糊匹配 | 消息与台词语义相近 | 相似度超过阈值即触发（默认 60%） |

支持 **mp3 / wav / m4a** 三种音频格式。多条语音发送时，提示消息会列出每条语音的角色名和台词文本。超过 5 条消息限制时，多余语音自动合并为一条音频发送。

> 项目早期版本名为"三国杀语音插件"，现已通用化；管理指令前缀为 `/v`。

## 快速开始

### 1. 安装插件

将本仓库克隆或下载到 AstrBot 的 `data/plugins/` 目录下。

### 2. 获取语音数据

> **本仓库不包含语音素材**（涉及版权），需自行下载。项目提供了自动爬取脚本，数据来源为公开 Wiki。

#### 环境准备

```bash
pip install pandas openpyxl requests
```

#### 运行爬取

```bash
cd astrbot_plugin_xgs_voice
python download_sgs_voices.py
```

脚本会自动完成以下工作：

- 读取 `三国杀.xlsx` 中的 601 个武将名称
- 依次访问 Wiki 页面提取音频链接和台词文本
- 将 MP3 文件下载到 `voice/sgs_voices/<武将名>/` 目录（与插件新目录结构一致）
- 支持**断点续传**：中途中断后重新运行会自动跳过已下载的武将

全部下载约需 2-3 小时（脚本内置了防封延迟）。下载完成后插件即可正常使用。

#### 文件命名规则

语音文件存放在 `voice/sgs_voices/<角色名>/` 目录下，格式为 `<序号>_<台词文本>.mp3`（也支持 .wav / .m4a）：

```
voice/sgs_voices/
├── SP关羽/
│   ├── 01_以义传魂，以武入圣！.mp3
│   └── 02_义击逆流，武安黎庶。.mp3
├── 曹操/
│   ├── 01_宁教我负天下人，休教天下人负我！.mp3
│   └── 05_不可能，绝对不可能.mp3
└── ...
```

### 3. 添加更多语音库（分类）

语音库统一放在 **`voice/` 大目录**下——一个语音库就是"一个含角色子文件夹的文件夹"。`voice/sgs_voices` 是默认的语音库，你可以在 `voice/` 下直接新建文件夹放入其它类型的音频，重启插件或执行 `/v reload` 后即可生效：

```
astrbot_plugin_xgs_voice/
└── voice/                  # 语音库大目录
    ├── sgs_voices/         # 语音库 1：三国杀（默认）
    │   └── 曹操/01_xxx.mp3
    ├── 鬼畜语录/           # 语音库 2：自定义（文件夹名即库名）
    │   └── 张三/01_xxx.mp3
    └── 原神语音/           # 语音库 3
        └── 刻晴/01_xxx.mp3
```

- 库内角色名与其它库重名时，聊天中用「库名+角色名」即可精确点播（如 `鬼畜语录张三3`），纯角色名会匹配第一个语音库。
- 若想把语音库放在插件目录之外，有两种方式：
  - `audio_root`：把整个语音库大目录指向其它位置（绝对路径或相对插件目录），该目录下的一级子文件夹同样按语音库识别，此时 `voice/` 不再扫描；
  - `extra_lib_dirs`：**额外语音库目录列表**，`voice/` 自动识别保持不变，同时把任意位置的库目录追加进来。每项既可以是单个库目录（其下就是角色文件夹，如某个 sgs 式库），也可以是包含多个库的大目录；`default_lib` 用于指定默认语音库（自动检测失败时的兜底）。

```
示例：voice/ 内置库 + 两个外部库（在配置 extra_lib_dirs 中填写）
extra_lib_dirs:
  - D:/voices/my_sgs        # 单个库目录：其下直接是 角色名/01_xxx.mp3
  - D:/voices/更多库         # 大目录：其下每个一级文件夹是一个库
```

配置修改后执行 `/v reload`（或重载插件）即可生效。

### 4. 启动

重启 AstrBot 或在 WebUI 中重载插件。插件会自动扫描并建立索引。

## 管理指令

| 指令 | 说明 |
|------|------|
| `/v help` | 显示帮助信息与当前状态 |
| `/v list` | 列出所有语音库及各自角色数 |
| `/v list <库名>` | 生成并发送指定语音库的角色列表图片 |
| `/v list <库名> <角色名>` | 列出该角色文件夹下的音频文件（台词）；只输角色名也可全库查找 |
| `/v stats` | 查看触发次数、语音库数、角色数、关键词数等统计 |
| `/v reload` | 重新加载配置并重新扫描音频目录 |

> 全部角色列表图片无专用命令，群聊发送「角色列表」触发词即可（兼容旧词「英雄列表」）。

## 配置项

以下参数可在 AstrBot WebUI 的插件管理页面中调整：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| LLM 唤醒词列表 | list | 问号、疑问词等 | 消息包含这些词时触发 LLM 回复（正则格式） |
| 唤醒词前缀 | string | `/` | 以此前缀开头的消息只触发语音，不触发 LLM |
| 需要前缀才触发 | bool | 否 | 开启后，消息必须以唤醒词前缀开头才会触发语音（如 `/曹操3`） |
| 仅群聊触发 | bool | 是 | 是否只在群聊中触发语音玩梗 |
| 私聊 LLM 模式 | string | smart | 私聊时的 LLM 行为：`always` / `smart` / `never` |
| 相似度阈值 | float | 0.6 | 模糊匹配的相似度门槛（0-1） |
| 语音库大目录 | string | `voice` | 语音库根目录（相对插件目录或绝对路径），其下每个一级文件夹视为一个语音库；留空自动检测 |
| 额外语音库目录列表 | list | 空 | 在 `voice/` 自动识别之外追加的库目录，每项可为单个库目录或含多库的大目录，支持任意位置 |
| 默认语音库目录 | string | `voice/sgs_voices` | 默认语音库所在目录，自动检测不到语音库时的兜底 |
| 关键词最短长度 | int | 2 | 过滤过短的台词关键词（如单字"杀""死"），设为 1 关闭过滤 |
| 合并缓存保留天数 | int | 30 | 自动清理超过该天数的合并音频缓存，0 表示不清理 |

> `extra_lib_dirs` 等新配置项在 AstrBot WebUI 插件管理页面的配置表单中设置；插件更新后需**重新加载插件**（或重启 AstrBot）新配置项才会出现。

## 智能回复机制

插件会自动判断一条消息是否需要 LLM 参与回复：

- **群聊普通消息**：只发语音，不触发 LLM。
- **群聊 @机器人 + 纯玩梗**：只发语音。
- **群聊 @机器人 + 包含唤醒词**：发语音并调用 LLM 回复。
- **私聊**：根据 `private_chat_llm_mode` 配置决定行为。
- **唤醒词前缀消息**（如 `/不可能`）：只发语音，跳过 LLM。
- **需要前缀模式**：开启后只有带前缀的消息才触发语音，普通消息不受影响。

## 依赖

- Python 3.8+
- [AstrBot](https://github.com/RockChinQ/AstrBot) 框架
- [Pillow](https://python-pillow.org/)（角色列表图片生成，可选）

- [ffmpeg](https://ffmpeg.org/)（mp3/m4a 转 WAV 以兼容 qq_official 等平台 + 音频合并，可选）
