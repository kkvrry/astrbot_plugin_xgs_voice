# 三国杀语音插件

AstrBot 语音插件 —— 在群聊中发送三国杀经典台词关键词，自动回复对应语音片段。支持关键词精确匹配与模糊匹配，并能智能判断是否需要调用 LLM 回复。

## 功能一览

| 功能 | 触发方式 | 示例 |
|------|----------|------|
| 点播指定语音 | `英雄名+序号` | `SP关羽3` → 发送 SP关羽 第 3 条语音 |
| 发送全部语音 | `英雄名+0` | `曹操0` → 依次发送曹操所有语音（超出 5 条自动合并） |
| 随机播放 | `英雄名`（不带序号） | `周瑜` → 随机发送一条周瑜语音（不重复） |
| 随机台词 | `随机台词+数字` | `随机台词3` → 从全部英雄中随机 3 条语音（上限 5 条） |
| 英雄列表 | `英雄列表` | 返回所有英雄名的精美排版图片（按拼音排序） |
| 关键词匹配 | 消息中包含台词关键词 | `不可能` → 发送 "不可能，绝对不可能" 语音 |
| 模糊匹配 | 消息与台词语义相近 | 相似度超过阈值即触发（默认 60%） |

多条语音发送时，提示消息会列出每条语音的英雄名和台词文本。超过 5 条消息限制时，多余语音自动合并为一条音频发送。

## 快速开始

### 1. 安装插件

将本仓库克隆或下载到 AstrBot 的 `data/plugins/` 目录下。

### 2. 获取语音数据

> **本仓库不包含语音素材**（涉及版权），需自行下载。项目提供了自动爬取脚本，数据来源为公开 Wiki。

#### 环境准备

```bash
pip install pandas openpyxl requests
```

#### 运行爬取

```bash
cd astrbot_plugin_xgs_voice
python download_sgs_voices.py
```

脚本会自动完成以下工作：

- 读取 `三国杀.xlsx` 中的 601 个武将名称
- 依次访问 Wiki 页面提取音频链接和台词文本
- 将 MP3 文件下载到 `sgs_voices/<武将名>/` 目录
- 支持**断点续传**：中途中断后重新运行会自动跳过已下载的武将

全部下载约需 2-3 小时（脚本内置了防封延迟）。下载完成后插件即可正常使用。

#### 文件命名规则

语音文件存放在 `sgs_voices/<英雄名>/` 目录下，格式为 `<序号>_<台词文本>.mp3`：

```
sgs_voices/
├── SP关羽/
│   ├── 01_以义传魂，以武入圣！.mp3
│   └── 02_义击逆流，武安黎庶。.mp3
├── 曹操/
│   ├── 01_宁教我负天下人，休教天下人负我！.mp3
│   └── 05_不可能，绝对不可能.mp3
└── ...
```

### 3. 启动

重启 AstrBot 或在 WebUI 中重载插件。插件会自动扫描 `sgs_voices/` 目录并建立索引。

## 管理指令

| 指令 | 说明 |
|------|------|
| `/sgs help` | 显示帮助信息与当前状态 |
| `/sgs hero_list` | 生成并发送英雄列表图片 |
| `/sgs stats` | 查看触发次数、英雄数、关键词数等统计 |
| `/sgs reload` | 重新加载配置并重新扫描音频目录 |

## 配置项

以下参数可在 AstrBot WebUI 的插件管理页面中调整：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| LLM 唤醒词列表 | list | 问号、疑问词等 | 消息包含这些词时触发 LLM 回复（正则格式） |
| 唤醒词前缀 | string | `/` | 以此前缀开头的消息只触发语音，不触发 LLM |
| 需要前缀才触发 | bool | 否 | 开启后，消息必须以唤醒词前缀开头才会触发语音（如 `/曹操3`） |
| 仅群聊触发 | bool | 是 | 是否只在群聊中触发语音玩梗 |
| 私聊 LLM 模式 | string | smart | 私聊时的 LLM 行为：`always` / `smart` / `never` |
| 相似度阈值 | float | 0.6 | 模糊匹配的相似度门槛（0-1） |

## 智能回复机制

插件会自动判断一条消息是否需要 LLM 参与回复：

- **群聊普通消息**：只发语音，不触发 LLM。
- **群聊 @机器人 + 纯玩梗**：只发语音。
- **群聊 @机器人 + 包含唤醒词**：发语音并调用 LLM 回复。
- **私聊**：根据 `private_chat_llm_mode` 配置决定行为。
- **唤醒词前缀消息**（如 `/不可能`）：只发语音，跳过 LLM。
- **需要前缀模式**：开启后只有带前缀的消息才触发语音，普通消息不受影响。
